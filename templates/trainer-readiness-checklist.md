# Trainer subject-matter readiness checklist

Use this checklist before teaching a product, capability, or technical topic
that is new to you.

**Subject-matter readiness** means knowing enough about the topic to explain
its intended use, limits, evidence requirements, and safe stopping points. It
does not mean becoming the product's deepest technical expert.

## 2. Build a first-party source pack

Use current sources from the organization that publishes or maintains the
product. Record the access date because documentation and product behavior can
change.

| Source type | Link or title | Accessed | Claim it supports |
| --- | --- | --- | --- |
| Overview or learning course |  |  |  |
| Technical documentation |  |  |  |
| Limitations or responsible-use guidance |  |  |  |
| Release notes or change log |  |  |  |
| Internal course library (private, if approved) |  |  |  |

Do not teach a capability based only on a marketing page, an old tutorial, or
an unverified example.

When using the internal course library, search for existing lesson plans,
labs, demos, rubrics, and product notes before creating new material. Repurpose
only content cleared for this audience. Do not copy private learner data,
unpublished exam content, credentials, provider-private prompts, or internal
identifiers into a public repository.

## 3. Map capability to evidence

- [ ] I can explain what the capability does.
- [ ] I can explain what it does not establish.
- [ ] I can name the evidence a learner should inspect.
- [ ] I can show one positive path.
- [ ] I can show one degraded or failure path.
- [ ] I can identify when human approval is required.

## 4. Rehearse the explanation

Explain the topic without reading from the source pack. Then answer:

1. What decision does this capability support?
2. What could go wrong?
3. How would the learner notice?
4. What should the learner do next?
5. What claim am I still unable to support?

If you cannot answer one of these questions, narrow the lesson or continue
learning before delivery.

## 5. Make the readiness decision

Choose one:

- **Ready:** I can teach the stated boundary and explain the evidence.
- **Ready with a boundary:** I can teach only the named subset; the rest is
  explicitly out of scope.
- **Not ready:** I need more source review or a subject-matter partner before
  teaching this topic.

Record the decision in the workshop revision record when it changes the
lesson, demo, worksheet, or rubric.
