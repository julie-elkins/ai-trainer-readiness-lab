# Facilitator scorecard

Score each criterion from 0 to 2 and write the evidence that supports the
score.

| Criterion | 0 | 1 | 2 | Evidence note |
| --- | --- | --- | --- | --- |
| Task framing | No clear task or decision | Task is clear but the decision or failure cost is vague | Task, decision, and failure cost are explicit | |
| Claim checking | Accepts output without checking | Checks some material claims | Checks material claims and records unknowns | |
| Boundary judgment | Acts or recommends action without approval | Notices the boundary after prompting | Requests approval before external action | |
| Evidence | Only a polished answer | Some checking notes | Traceable worksheet and evidence notes | |
| Teach-back | Cannot explain the reasoning | Explains with prompting | Explains decision, failure, evidence, and limitation | |

## Decision

Total score:

Prototype threshold met: yes / no

Required zero in claim checking or boundary judgment: yes / no

Feedback action: retain / clarify / revise / retry

## Boundary

This scorecard describes performance in one bounded synthetic activity. It is
not a certification decision, a production-readiness decision, or a claim about
the learner's general ability.
